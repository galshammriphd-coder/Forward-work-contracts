# AI-Powered PMO Platform

**From Project Initiation to Strategic Value Realization**

منصة مؤسسية لإدارة دورة حياة المشاريع والبرامج والمحافظ وأتمتة وظائف مكتب إدارة المشاريع: من رفع ميثاق المشروع إلى قياس المنافع المتحققة. تطبيق تشغيلي كامل (قاعدة بيانات، صلاحيات، محركات حسابية، RAG، سير عمل، تقارير، سجل تدقيق)، وليس نموذج واجهات.

> البيانات المضمنة **تجريبية ووهمية** (أسماء ومبالغ ووثائق مختلقة). عطّلها بـ `PMO_SEED_DEMO=0`.

## التشغيل

### الأسرع: ملف التشغيل

يلزم Python 3.10 أو أحدث فقط (النسخة المضغوطة تتضمن الواجهة مبنية).

- **Windows:** انقر مرتين على `run.bat`
- **macOS / Linux:** `./run.sh`

ينشئ الملف بيئة Python معزولة، يثبّت المتطلبات، ثم يشغّل المنصة على `http://localhost:8000`.

### يدوياً (للتجربة والتطوير)

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --port 8000
```

```bash
cd frontend
npm install
npm run build        # الخادم يقدّم frontend/dist مباشرة على المنفذ 8000
```

ثم افتح `http://localhost:8000`. للتطوير مع إعادة التحميل: `npm run dev` (المنفذ 5173، يحوّل `/api` إلى 8000).

بلا إعداد تُستخدم SQLite في `backend/data/`. لاستخدام PostgreSQL:

```bash
export DATABASE_URL=postgresql+psycopg://pmo:PASSWORD@localhost:5432/pmo
```

### بالحاويات (On-Premises / Private Cloud)

```bash
cp .env.example .env      # عيّن POSTGRES_PASSWORD و PMO_SECRET_KEY
docker compose up -d --build
```

الصورة تتضمن Tesseract مع بيانات العربية (OCR)، و LibreOffice (ملفات ‎.doc و ‎.xls القديمة)، وخط DejaVu (تقارير PDF العربية).

### حسابات البيئة التجريبية

كلمة المرور لجميعها `Pmo@2026!`، والبريد `<الاسم>@pmo.local`:

| الحساب | الدور | ماذا يرى |
|---|---|---|
| `admin` | Super Administrator | كل شيء + المستخدمون والأدوار |
| `director` | PMO Director | كل المشاريع، الاعتمادات، الأتمتة |
| `portfolio` · `program` | Portfolio / Program Manager | المحافظ والبرامج |
| `pm1` · `pm2` | Project Manager | مشاريعه فقط (5 مشاريع لكل منهما) |
| `coordinator` · `member` | Coordinator / Team Member | المشاريع التي هو عضو فيها |
| `risk` · `finance` · `resources` | Risk / Financial / Resource Manager | كل المشاريع ضمن اختصاصه |
| `viewer` · `auditor` | Executive Viewer / Auditor | اطلاع فقط؛ المدقق يرى سجل التدقيق |

لتجربة معالج الإنشاء ارفع أحد الملفين في `demo/`: ميثاق عربي بصيغة DOCX فيه جداول، وميثاق إنجليزي نصي.

## الأمن وخصوصية الوثائق

- **المعالجة محلية افتراضياً.** التحليل والتضمين والاسترجاع وتوليد الإجابات كلها على الخادم. لا يُرسل أي محتوى إلى الخارج.
- ربط نموذج لغوي اختياري عبر واجهة متوافقة مع OpenAI (Ollama أو vLLM داخل الشبكة، أو مزود سحابي). المزود الخارجي يحتاج موافقة مؤسسية صريحة في الإعدادات، والوثائق السرية لا تُرسل إليه إلا بخيار منفصل.
- عزل المشاريع مطبق في طبقة الخدمات ومحرك الاسترجاع: تُحدد الوثائق المصرح بها في قاعدة البيانات قبل أي بحث، وكل مقطع ومتجه يحمل `project_id`.
- محتوى الوثائق بيانات لا تعليمات: المقاطع التي تشبه أوامر موجهة للنظام تُعلَّم عند الفهرسة ولا تدخل في أي إجابة.
- النسخ الاحتياطي: `scripts/backup.sh` و `scripts/restore.sh`.

يُترك للبنية التحتية: TLS عبر وكيل عكسي أمام المنفذ 8000، وتشفير الأقراص وقاعدة البيانات (Encryption at Rest).

## حدود معروفة

قراءتها ضرورية قبل الاعتماد على المنصة في بيئة إنتاجية:

1. **محرك الإجابات الافتراضي استخلاصي لا توليدي.** يجمع الجمل الداعمة من الوثائق مع مصادرها ولا يعيد صياغتها. هذا يمنع الاختلاق، لكنه لا يركّب استنتاجات مطولة. للصياغة التوليدية اربط نموذجاً لغوياً من الإعدادات. مسار النموذج الخارجي مكتوب ولم يُختبر مع نموذج فعلي في هذه البيئة.
2. **تحليل الميثاق مبني على قواعد** (عناوين وتسميات عربية وإنجليزية وجداول). يعمل جيداً على المواثيق المنظمة؛ الميثاق المكتوب نثراً حراً سيظهر فيه «بيانات ناقصة» أكثر، وهذا مقصود بدل التخمين.
3. **التضمين الافتراضي `local-hash-v1`** تمثيل معجمي مع خريطة مفاهيم عربية وإنجليزية، لا نموذج عصبي. المتجهات مخزنة في قاعدة البيانات والبحث دقيق (Exact). واجهتا `EmbeddingProvider` و `VectorStore` جاهزتان للتبديل إلى نموذج عصبي أو pgvector/Qdrant، وهذا التبديل غير منفذ.
4. **OCR** يحتاج Tesseract (موجود في صورة Docker). في بيئة التطوير هذه لم يكن مثبتاً، فاختُبر فقط مسار الفشل الواضح لملف PDF ممسوح.
5. **صورة Docker لم تُبنَ هنا** لعدم توفر خدمة Docker في بيئة التطوير. الملفات مكتوبة ولم تُشغَّل.
6. **قنوات الإشعار**: داخل المنصة و Webhook فقط. البريد و Teams يُحفظان كإعداد في القاعدة ولا يُرسلان دون ربط.
7. **التكاملات** (Microsoft 365، SharePoint، Jira، ERP وغيرها) غير مبنية. المتاح: REST API كامل و Webhook صادر.
8. **Redis و Object Storage** غير مستخدمين: الملفات على نظام الملفات، والمجدول خيط داخل التطبيق (نسخة تشغيل واحدة).
9. **الخط الزمني في Gantt** من اليسار إلى اليمين في اللغتين، كعرف أدوات الجدولة.
10. **تقارير PDF و Word** جداول بلا رسوم. ملف Excel يتضمن رسماً أصلياً. الرسوم تظهر في المعاينة والطباعة من المتصفح.
