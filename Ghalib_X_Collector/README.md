# Ghalib X Data Collector

<div dir="rtl">

**منصة محلية لإدارة عمليات البحث في منصة X وجمع البيانات المتاحة وتنظيمها وتحليلها عبر تجربة متصفح متكاملة — دون X API ودون مفاتيح API ودون خدمات جمع خارجية.**

تعمل المنصة بالكامل على جهازك: واجهة Streamlit عربية (RTL)، ومتصفح Chromium/Edge يديره التطبيق عبر Playwright، وقاعدة بيانات SQLite محلية، وتحليلات Pandas/Plotly/scikit-learn، ونماذج Transformers محلية اختيارية.

---

## 1. كيف تعمل المنصة؟

1. تفتح المنصة نافذة متصفح مستقلة على `https://x.com`.
2. **تسجّل الدخول بنفسك** في تلك النافذة. التطبيق لا يطلب كلمة المرور ولا يقرؤها ولا يخزنها؛ تُحفظ ملفات تعريف الارتباط فقط في مجلد الجلسة المحلي كما يفعل أي متصفح.
3. تصوغ البحث (هاشتاق / اسم مستخدم / كلمات مفتاحية / بحث متقدم) فتحوّله المنصة إلى استعلام بمعاملات البحث المتقدم الرسمية في X (`from:` و`since:` و`until:` و`lang:` و`min_faves:` و`filter:` …).
4. تفتح عملية الجمع صفحة نتائج البحث في المتصفح المسجّل وتتصفحها بالتمرير **بوتيرة بشرية** (تأخير عشوائي قابل للضبط)، وتقرأ المنشورات من مصدرين:
   - **استجابات GraphQL** التي يستلمها موقع X نفسه داخل صفحتك (أدق مصدر: العدادات الكاملة، اللغة، الوسوم، الروابط، بيانات صاحب الحساب).
   - **الصفحة المعروضة (DOM)** كمصدر احتياطي لما لم يظهر في الاستجابات.
5. تُحفظ كل نتيجة مع مصدرها ووقت جمعها، وتُزال التكرارات، ثم تعمل دورة التنظيف والمعالجة تلقائياً، وتصبح البيانات متاحة للوحات والتحليلات والتقارير والتصدير.

> **بديل عملي عند تعذر الجمع الآلي:** صفحة «إنشاء عملية جمع ← استيراد ملف» تقبل ملف **HAR** تحفظه من أدوات المطوّر في متصفحك العادي (DevTools ← Network ← Save all as HAR) أثناء تصفحك نتائج البحث، وتستخرج منه المنشورات بالمحلل نفسه. وتقبل أيضاً ملفات JSON/CSV المصدّرة من هذا التطبيق (للنقل بين الأجهزة).

## 3. التثبيت والتشغيل على Windows (الطريقة الأسهل)

1. انسخ مجلد `Ghalib_X_Collector` إلى أي مكان على جهازك (مثلاً `C:\Ghalib_X_Collector`).
2. انقر نقراً مزدوجاً على **`run_windows.bat`**.
   - في التشغيل الأول: ينشئ بيئة افتراضية `.venv` ويثبّت المكتبات ومتصفح Chromium (عدة دقائق).
   - في المرات التالية: يشغّل التطبيق مباشرة.
3. يفتح المتصفح تلقائياً على `http://localhost:8501`. (إن لم يفتح، افتح الرابط يدوياً).
4. لإيقاف التطبيق: أغلق نافذة الأوامر السوداء.

### التثبيت اليدوي (لأي نظام)

```bat
cd C:\Ghalib_X_Collector
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m playwright install chromium
.venv\Scripts\python -m streamlit run app.py
```

على Linux/macOS: `./run_linux_mac.sh`

### تفعيل نماذج الذكاء الاصطناعي المحلية (اختياري)

```bat
.venv\Scripts\python -m pip install -r requirements-ai.txt
```

تُحمَّل النماذج مرة واحدة إلى `data\models` ثم تعمل دون اتصال. لمنع أي اتصال بعد التحميل اضبط متغير البيئة `HF_HUB_OFFLINE=1`. بدون هذه الخطوة تعمل المحركات المدمجة (معجم المشاعر، قواعد الكيانات، النمذجة الموضوعية، التلخيص الاستخلاصي).

## 4. أول استخدام — خطوة بخطوة

1. **الاتصال بمنصة X** ← اضغط «فتح منصة X» ← تفتح نافذة متصفح ← سجّل الدخول ← ارجع واضغط «التحقق من حالة الاتصال» حتى تظهر الحالة **متصل**.
2. **محرك البحث** ← اختر نوع البحث واكتب العبارة، وستظهر الاستعلامات الفعلية التي ستُنفذ. يمكنك «عرض النتائج في نافذة المتصفح» أو «حفظ إعدادات البحث».
3. **إنشاء عملية جمع** ← سمِّ العملية وحدد الحد الأقصى للمنشورات ← «إنشاء العملية» (مع «بدء التنفيذ فوراً»).
4. **عمليات الجمع** ← تابع التقدم مباشرة (المستلمة/الجديدة/المكررة/المعالجة، تقدم كل استعلام، السجل، وصورة حية من المتصفح). يمكنك الإيقاف والاستئناف وإعادة التنفيذ.
5. استعرض النتائج في **الرئيسية** و**المنشورات** و**الحسابات** و**الهاشتاقات**، ثم **التحليلات** و**المقارنات**، وأخيراً **التقارير** و**تصدير البيانات**.

### أمثلة بحث

| النوع | المدخل | الاستعلام المنفذ في X |
|---|---|---|
| هاشتاقات (أي منها) | `#الذكاء_الاصطناعي` ، `#رؤية_السعودية_2030` | `(#الذكاء_الاصطناعي OR #رؤية_السعودية_2030)` |
| اسم مستخدم + موضوع | `@account` + «الذكاء الاصطناعي» + فترة | `from:account الذكاء الاصطناعي since:2026-01-01 until:2026-02-01` |
| كلمات منطقية | `التحول الرقمي AND البيانات` | `التحول الرقمي البيانات` |
| عبارة محددة | `"Artificial Intelligence" OR AI NOT crypto` | `"Artificial Intelligence" OR AI -crypto` |
| متقدم | لغة، نوع منشور، حد أدنى للإعجابات، مستبعدات | `… lang:ar -filter:replies min_faves:10 -إعلان` |

## 6. البيانات المستخرجة لكل منشور

`Post ID` · `Post Text` · `Username` · `Display Name` · `Profile URL` · `Post URL` · `Published Date` · `Published Time` · `Language` · `Hashtags` · `Mentions` · `Replies Count` · `Reposts Count` · `Likes Count` · `Views Count` · `Search Keyword` · `Collection Date`
بالإضافة إلى: `Quotes/Bookmarks Count`، نوع المنشور (أصلي/رد/اقتباس/إعادة نشر)، الروابط الخارجية، المرفقات (صور/فيديو)، معرف المحادثة، الرد على، المنشور المقتبس، المصدر (graphql/dom/import).

- **العدادات غير المتاحة تُخزن فارغة (NULL) وتُعرض «غير متاح»** ولا تُحسب صفراً في المتوسطات.
- لكل التقاط سجل مصدر (`post_sources`) ولقطة عدادات (`post_metrics`)، فترى تطور التفاعل بين عمليات الجمع.

## 7. دورة المعالجة (تحافظ على الأصل)

التحقق ← وسم النصوص المكررة (دون حذف) ← تنظيف النص ← المسافات والرموز ← استخراج الهاشتاقات ← استخراج الإشارات ← تحديد اللغة ← توحيد التاريخ والوقت (UTC + المنطقة الزمنية المختارة) ← التحقق من الروابط ← القيم المفقودة ← التوثيق.
كل خطوة تُسجّل في `processing_logs`. النص الأصلي `raw_text` والسجل الخام `raw_json` لا يُعدَّلان أبداً؛ المخرجات تُكتب في أعمدة منفصلة (`clean_text`، `detected_language`، `validation_notes`…).

## 8. التحليلات والذكاء الاصطناعي (محلية بالكامل)

| الوظيفة | المحرك المدمج (متاح دائماً) | المحرك الاختياري (requirements-ai.txt) |
|---|---|---|

| الموضوعات | TF-IDF + NMF (scikit-learn) | — |

## 9. قاعدة البيانات

ملف SQLite واحد: `data\ghalib_x.db` يُنشأ تلقائياً عند أول تشغيل من `database\schema.sql`.

الجداول المطلوبة: `search_jobs` · `posts` · `accounts` · `hashtags` · `post_hashtags` · `post_metrics` · `collection_logs` · `processing_logs` · `sentiment_results` · `topic_results` · `exports` · `application_settings`
جداول إضافية: `job_posts` (ربط العمليات بالمنشورات) · `post_sources` (السجل الخام لكل التقاط) · `entity_results` · `saved_searches` · `app_users` · `audit_log`
مع العلاقات (Foreign Keys) والفهارس، ووضع WAL للعمل المتزامن بين الواجهة وعملية الجمع.

## 10. الأمان والخصوصية

- تشغيل محلي على `127.0.0.1` فقط؛ قاعدة البيانات والجلسة والتصدير على جهازك.
- **لا تُخزن كلمات مرور X**. مجلد الجلسة `data\browser_session` مقيد بصلاحيات مستخدم Windows الحالي (`icacls`).
- إدارة الصلاحيات (اختيارية): مستخدمون بأدوار **مدير / محلل / مشاهد**، وكلمات المرور مشفرة بـ PBKDF2-SHA256.
- سجل تدقيق لكل الإجراءات المهمة (فتح المتصفح، إنشاء العمليات، التصدير، الحذف، الاستعادة…).
- نسخ احتياطي متسق أثناء التشغيل، واستعادة تحفظ نسخة أمان تلقائياً قبل الاستبدال، وحذف بيانات عملية أو كل البيانات.
- إحصاءات الاستخدام في Streamlit معطلة، ولا تُحمَّل خطوط أو موارد من الإنترنت في الواجهة.
- تُعادل الخلايا التي تبدأ بـ `= + - @` في Excel لمنع حقن الصيغ من نصوص المنشورات.

## 12. الاختبارات

```bat
run_windows.bat test
```
أو `python -m pytest -q`. تغطي: الاتصال بقاعدة البيانات والمخطط، إنشاء العمليات، حفظ المنشورات، إزالة التكرار، تنظيف النصوص العربية، اكتشاف اللغة، المعالجة، التحليلات، التصدير (XLSX/CSV/JSON/PDF)، الرسوم البيانية، النسخ الاحتياطي والاستعادة، إدارة الجلسة واستمرارها بعد إعادة تشغيل المتصفح، ومعالجة الأخطاء.

اختبارات المتصفح تشغّل **Chromium حقيقياً** وتنفذ دورة الجمع كاملة (الالتقاط، التمرير، الإيقاف والاستئناف، انتهاء الجلسة، الحد الأقصى، جمع بيانات الحساب، المصدر الاحتياطي DOM)، لكن طلبات `x.com` تُجاب داخل الاختبار ببيانات اختبار محلية (`tests/fixtures.py`) تحاكي بنية صفحات X — فلا تتصل الاختبارات بالمنصة ولا تُكتب بياناتها في قاعدتك. **لا توجد أي بيانات وهمية في التطبيق نفسه**؛ القاعدة تبدأ فارغة.

## 13. حدود يجب معرفتها (بشفافية)

- **شروط استخدام X:** تمنع شروط X الجمع الآلي دون إذن. الأداة تعمل بحسابك وبطلب منك وبوتيرة بشرية معتدلة، لكن مسؤولية الاستخدام والالتزام بالشروط والأنظمة (ومنها نظام حماية البيانات الشخصية) تقع على المستخدم. استخدم حدوداً معقولة؛ الإفراط قد يؤدي لتقييد الحساب مؤقتاً.
- **ما تتيحه X لحسابك فقط:** تعرض X للمستخدم المسجل عدداً محدوداً من النتائج لكل بحث، وقد تفرض حدوداً للقراءة. عند ظهور رسالة خطأ أو حد، تنتظر الأداة ثم تعيد المحاولة، وإن تكرر تتوقف العملية بحالة «متوقفة» ويمكن استئنافها لاحقاً (يستأنف تبويب «الأحدث» من تاريخ أقدم منشور مجمّع).
- **تغيّر واجهة X:** تغيّر X بنية صفحاتها وردودها من حين لآخر. المحلل مرن (يدعم البنيتين القديمة والجديدة لبيانات الحساب، ويقرأ من الصفحة كاحتياط)، وإن توقف أحد المصدرين يستمر الآخر. إن تغيرت البنية جذرياً يلزم تحديث `result_importer.py` أو `dom_extractor.py`.
- **التحقق على x.com الحقيقي:** بُني هذا الإصدار واختُبر في بيئة لا تملك حساب X، لذا جرت الاختبارات على محاكاة محلية لبنية X. أول تشغيل فعلي على حسابك هو التحقق الحقيقي؛ ابدأ بعملية صغيرة (50–100 منشور) وراجع «سجل العمليات».
- **حظر تسجيل الدخول الآلي:** إن رفض X الدخول من متصفح Playwright، اختر «Microsoft Edge المثبت» من الإعدادات، أو استخدم مسار استيراد HAR.
- **الوضع المخفي (Headless):** لا يمكن تسجيل الدخول فيه؛ سجّل الدخول أولاً في نافذة مرئية ثم فعّله إن أردت.
